Or install from the command line

macOS / Linux — no prerequisites (installs Python if needed):

curl -fsSL https://raw.githubusercontent.com/DarylNo/CardScanner/master/install.sh | bash
mtg-card-scanner

Any platform with Python 3.11+ or uv:

pipx install git+https://github.com/DarylNo/CardScanner
mtg-card-scanner

Then

  1. The desktop UI opens itself; first run shows a one-click Build card database step (~1 hour, once).
  2. Scan the QR code with your phone, accept the one-time certificate warning, and mount the phone over a tray.
  3. Tap Area on the phone, drag a box around the tray — done. Drop cards in; they identify, price, and file themselves.

macOS/Linux downloads are .tar.gz — extract, then run mtg-card-scanner (the executable bit is preserved). macOS binaries are unsigned — right-click → Open the first time. Windows will ask to allow the app through the firewall so the phone can connect. Source & issues on GitHub.
